Connect an AI client (MCP)

Codever ships its own MCP (Model Context Protocol) server, so you can connect an AI client — like VS Code + Copilot, Cursor or Claude Desktop — and let it search and read your own bookmarks and notes, right inside your editor or chat.

This is a power-user feature. If you just want to ask questions over your bookmarks and notes without any setup, use the built-in Ask Codever chat instead — no client, no configuration.

What your AI client can do

The Codever MCP server is read-only by design. It exposes exactly three tools:

  • search_entries — search your bookmarks and notes by text and tags.
  • get_entry — fetch a single bookmark or note by id, with its full content.
  • list_tags — list your tags with usage counts.
Read-only by architecture. There are no create, update or delete tools, and the MCP connection uses a separate, scoped credential — a connected client can never modify your data.

Before you start

  • You need a Codever account and must be logged in.
  • The MCP feature must be enabled for your account. If it isn't, the connection will be rejected — see Troubleshooting.
  • An MCP-capable client that supports OAuth (see the compatibility table below).

Connect your client

The server URL is the same everywhere. Authentication happens through your browser — no token to copy or paste: on first connect the client opens a Codever login, you approve, and it stores and refreshes the token for you.

{{ mcpUrl }}
VS Code

Create (or edit) .vscode/mcp.json in your workspace root and add: 

{{ vscodeConfig }}

Then start the server from the mcp.json editor (or via MCP: List Servers). VS Code opens a browser login the first time; after you approve, the codever tools appear in Copilot's agent mode tool picker.

Cursor / Claude Desktop

Add Codever to your client's MCP configuration (for Cursor: Settings → MCP → Add server; for Claude Desktop edit its claude_desktop_config.json): 

{{ genericConfig }}

On first use the client launches a browser login. Approve it once and the Codever tools become available.

Try it

Once connected, ask your AI client things like:

  • "Search my Codever bookmarks for MCP and summarize the top results."
  • "What tags do I use most in Codever?"
  • "Open my note about … and turn it into a checklist."

Client compatibility

Client Supported Notes
VS Code + Copilot Yes Browser-based OAuth; tools appear in agent mode.
Cursor Yes Browser-based OAuth.
Claude Desktop Yes Add via config; browser-based OAuth.
GitHub Copilot CLI Not supported Requires Dynamic Client Registration, which Codever intentionally does not allow. Use VS Code, Cursor or Claude Desktop instead.

Troubleshooting

  • Connection rejected / 403 — the MCP feature may not be enabled for your account yet. It's rolled out gradually.
  • Browser login doesn't open — make sure your client version supports OAuth for MCP and that pop-ups aren't blocked.
  • No tools appear — confirm the server URL is exactly {{ mcpUrl }} and that you completed the browser login.
