Hot Keys

  • Ctrl/Cmd+Shift+H - launches dialog with your bookmarks history (requires login)
  • Ctrl/Cmd+Shift+P - launches dialog with your pinned bookmarks (requires login)
  • Ctrl/Cmd+K - focus and select text in the search box
  • k k - press k twice to open the main link of the only visible bookmark (on the bookmark details page, or when a Pinned/History dialog or search results filter leaves exactly one bookmark) in a new tab
  • Enter - while a filter has focus (Pinned/History, side quick access, My Collections, inside a collection, or search results), opens the only matching bookmark in a new tab, or navigates to the only matching collection
